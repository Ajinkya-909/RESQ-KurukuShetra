# Frontend Architecture & UI/UX Documentation

This directory contains documentation for the RESQ client application built with React and interactive mapping tools.

## Scope & Contents
- **Component Architecture**: Breakdown of the Map Sandbox, Incident Reporter, Allocation Ledger, Conflict Banner, and Audit Log Feed.
- **Mapping & Spatial Visualization**: Configuration for Leaflet / Mapbox, rendering zone impact radii, helping point markers, and allocation trajectory vectors.
- **State Management & WebSockets**: Client-side handling of real-time server events, simulation states, and before/after allocation diffs.
- **Design System & Theme**: Color tokens, typography, dark/emergency mode styling, and accessible UI patterns.
