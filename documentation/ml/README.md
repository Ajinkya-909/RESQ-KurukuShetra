# Machine Learning & Multi-Agent System Documentation

This folder contains architecture specifications, model documentation, prompt engineering guides, and agent logic workflows for the RESQ AI engine.

## Scope & Contents
- **Needs Assessment Agent**: NLP parsing of unstructured disaster reports into structured demand vectors.
- **Priority & Severity Scoring**: Mathematical heuristics and scoring models for triage.
- **Optimization & Allocation Engine**: Proximity/capacity matching and greedy/LP resource distribution.
- **Duplicate Detection & Conflict Resolution**: Logic for catching overlapping aid assignments.
- **Agent Prompts & Tool Definitions**: Schemas and interfaces for LLM/heuristic agents.
