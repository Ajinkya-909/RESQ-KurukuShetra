# RESQ — Frontend Command Dashboard

React client application featuring an interactive spatial mapping interface, real-time allocation ledger, before/after reallocation visual diffs, and live agent reasoning logs.

## Structure
- `src/`
  - `components/`: MapView, AllocationTable, DiffBanner, IncidentReporter, AuditFeed.
  - `services/`: API and WebSocket hooks.
  - `styles/`: Clean, accessible emergency dashboard UI themes.
